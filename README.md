# MR Ingeniería Estructural

Sitio institucional de **MR Ingeniería Estructural**, estudio especializado en cálculo y diseño de estructuras de hormigón armado y metálicas para proyectos residenciales, comerciales e industriales.

**Demo publicada:** [estudioideamos.github.io/mr-ingenieria-estructural](https://estudioideamos.github.io/mr-ingenieria-estructural/)

## Secciones

- Inicio y propuesta de valor.
- Presentación del estudio.
- Servicios de ingeniería estructural.
- Diferenciales de trabajo.
- Proyectos.
- Contacto.

## Tecnología

Proyecto multipágina estático desarrollado con HTML, CSS y JavaScript. No necesita servidor de aplicaciones ni proceso de compilación.

## Estructura principal

```text
.
├── index.html
├── nosotros.html
├── servicios.html
├── proyectos.html
├── por-que-elegirnos.html
├── contacto.html
├── assets/
├── robots.txt
└── sitemap.xml
```

## Desarrollo local

Abrir `index.html` directamente o servir la carpeta con cualquier servidor HTTP local. Al modificar navegación, metadatos o estilos se deben revisar todas las páginas internas.

## Publicación

El repositorio está preparado para GitHub Pages desde la rama `main`. Los cambios enviados a esa rama se publican mediante el flujo incluido en `.github/`.

## Calidad

El sitio utiliza HTML semántico, diseño responsive, metadatos para buscadores y recursos locales. Antes de publicar conviene validar enlaces internos, formularios, versión móvil y sitemap.
